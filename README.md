## Installation
git clone https://github.com/muneeba-swivel/Arithmetic_operations_with_tool.git

## Set your .env file
add your OPENAI_API_KEY='your api key here'

## Add your pds into the doc folder
create a docs folder and insert your pdfs there

## Run the file
Run the python main.py file
also add your doc name

## Features

- Extracts text from PDF files in the docs/ folder

- Detects and solves arithmetic expressions (%, +, -, ×, ÷, roots, etc.)

- Built-in financial calculator:

    - Compound interest

    - Simple interest

    - Loan payment calculator

    - Future/present value

- Splits long PDFs into chunks for better LLM processing

- Context-aware query answering with arithmetic awareness
